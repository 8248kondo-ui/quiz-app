ステップ１：【@RequestMapping アノテーション】に関する問題

問１. @RequestMapping アノテーションの説明として正しいものを選べ。

1. コントローラクラスのメソッドに付与することで、指定したURLへのリクエスト時にそのメソッドが実行される。
2. @RequestMapping はクラスにのみ付与可能であり、メソッドに付与しても効果はない。
3. @RequestMapping を付与しなくても、すべてのメソッドがURLリクエストに応答する。
4. @RequestMapping はサービスクラスに付与するアノテーションであり、コントローラクラスには使用できない。

正解：1番

4. context-path の設定はURLには影響しないため「http://localhost:8081/top」と「http://localhost:8081/sample/top」はどちらでもアクセスできる。

ステップ７：【セッションスコープを利用するメソッド定義】に関する問題

問７. セッションスコープを利用するメソッド定義の説明として正しいものを選べ。

---Java---
@Controller
@SessionScope
public class ShoppingCartController {

    @Autowired
    private CartForm cartForm;

    @GetMapping("/cart/view")
    public String viewCart(Model model) {
        model.addAttribute("cart", cartForm);
        return "cart/view";
    }
}
----------

1. @SessionScope をコントローラクラスに付与することで、このコントローラのインスタンスがセッション単位で管理される。
2. @SessionScope はメソッドに付与するアノテーションであり、クラスに付与しても効果はない。
3. @SessionScope を付与したクラスは、すべてのユーザーで同じインスタンスが共有される。
4. @SessionScope を付与すると、cartForm の値はリクエストのたびにリセットされる。

正解：1番

ステップ１０：【主キー列でシーケンスを利用するエンティティの定義】に関する問題

問１０. 以下のエンティティ定義の説明として正しいものを選べ。

---Java---
@Entity
@Table(name = "orders")
public class Order {

    @Id
    @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "order_seq")
    @SequenceGenerator(name = "order_seq", sequenceName = "order_id_seq", allocationSize = 1)
    private Integer id;

    private Integer amount;

    // getter/setter 省略
}
----------

1. @SequenceGenerator の sequenceName にはDB上のシーケンス名を指定し、@GeneratedValue の generator には @SequenceGenerator の name を指定する。
2. @SequenceGenerator の name にはDB上のシーケンス名を指定する。
3. @GeneratedValue を付与するだけでシーケンスが使用され、@SequenceGenerator は不要である。
4. @Id を付与したフィールドには @GeneratedValue を付与できない。

正解：1番

ステップ１２：【外部参照元エンティティの定義（@ManyToOne / @JoinColumn）】に関する問題

問１２. @ManyToOne と @JoinColumn に関する説明として正しいものを選べ。

1. @ManyToOne は「多対1」の関係を表し、@JoinColumn の name 属性には外部キー列名を指定する。
2. @ManyToOne は「1対多」の関係を表し、参照元テーブルに複数の関連レコードを持たせる。
3. @JoinColumn の name 属性には、参照先テーブルのテーブル名を指定する。
4. @ManyToOne を付与したフィールドの型は、String 型でなければならない。

ステップ１６：【@NotNull と Integer 型のバリデーション】に関する問題

問１６. 以下のフォームクラスの説明として正しいものを選べ。

---Java---
public class OrderForm {

    @NotBlank
    private String productName;

    @NotNull
    private Integer quantity;

    // getter/setter 省略
}
----------

1. @NotNull を Integer 型に付与すると、フォームから値が送信されなかった（null の）場合にバリデーションエラーになる。
2. @NotNull を Integer 型に付与すると、空文字の入力もバリデーションエラーになる。
3. @NotBlank は数値型にも使用でき、Integer 型の quantity に付与するべきである。
4. Integer 型に @NotNull は付与できない。使用するには long 型に変更する必要がある。

正解：1番

ステップ１９：【th:each のステータス変数を利用した書き方】に関する問題

問１９. th:each のステータス変数の説明として正しいものを選べ。

---Thymeleaf---
<tr th:each="emp, st : ${empList}">
  <td th:text="${st.index}">0</td>
  <td th:text="${emp.name}">名前</td>
</tr>
----------

1. st.index は0から始まるインデックス番号を表し、1件目は「0」が表示される。
2. st.index は1から始まるカウンターを表し、1件目は「1」が表示される。
3. ステータス変数（st）は省略不可であり、必ず宣言しなければ th:each は動作しない。
4. th:each のステータス変数で使えるのは index のみである。

正解：1番

ステップ２０：【リンク式 @{} でパラメータ値を含める書き方】に関する問題

問２０. 以下のリンク式の説明として正しいものを選べ。
ただし、member.id には「10」が格納されているとする。

---Thymeleaf---
<a th:href="@{/member/edit(id=${member.id})}">編集</a>
----------

1. 生成されるURLは「/member/edit?id=10」となる。
2. 生成されるURLは「/member/edit/10」となる（パスに直接埋め込まれる）。
3. 生成されるURLは「/member/edit(id=10)」となる。
4. @{} 内で ${} は使えないため、このコードはエラーになる。

ステップ２１：【個別画面をレイアウトテンプレートに埋め込む記述】に関する問題

問２１. layout:fragment を使ったレイアウト機能の説明として正しいものを選べ。

1. レイアウトテンプレートに layout:fragment="content" を定義し、個別画面に layout:decorate でレイアウトを指定することで、個別画面のコンテンツが埋め込まれる。
2. 個別画面に layout:fragment を定義するだけで、自動的にレイアウトテンプレートが読み込まれる。
3. layout:decorate はレイアウトテンプレートにのみ記述し、個別画面には記述しない。
4. layout:fragment と th:fragment はどちらを使っても同じ動作になる。

正解：1番
