ステップ１：【@Controller / @Service / @Repository の役割】に関する問題

問１. 以下のコードの説明として正しいものを選べ。

---Java---
@Service
public class ProductService {

    @Autowired
    private ProductRepository productRepository;

    public List<Product> findAll() {
        return productRepository.findAll();
    }
}
----------

1. @Service はビジネスロジック層のクラスに付与するアノテーションであり、DIコンテナに登録される。
2. @Service はデータアクセス層のクラスに付与するアノテーションであり、DB操作専用のメソッドを定義する。
3. @Service はコントローラ層のクラスに付与するアノテーションであり、HTTPリクエストを受け取る。
4. @Service を付与したクラスは、@Autowired で自動注入できない。

正解：1番

ステップ２：【@GetMapping / @PostMapping の使い分け】に関する問題

問２. 以下のコードの説明として誤っているものを選べ。

---Java---
@Controller
public class UserController {

    @GetMapping("/user/form")
    public String showForm() {
        return "user/form";
    }

    @PostMapping("/user/form")
    public String submitForm(UserForm form) {
        return "redirect:/user/complete";
    }
}
----------

1. @GetMapping("/user/form") は、GETリクエストで「/user/form」にアクセスしたときに showForm() が実行される。
2. @PostMapping("/user/form") は、POSTリクエストで「/user/form」にアクセスしたときに submitForm() が実行される。
3. @GetMapping と @PostMapping は同じURLパスに対してそれぞれ定義できる。
4. @PostMapping はGETリクエストでもPOSTリクエストでも実行される。

正解：4番

ステップ４：【return "redirect:/xxx" の動作】に関する問題

問４. 以下のコードが実行された後の動作として正しいものを選べ。

---Java---
@PostMapping("/product/register")
public String register(ProductForm form) {
    productService.save(form);
    return "redirect:/product/list";

----------

1. ブラウザは「/product/list」へのGETリクエストを新たに発行し、URLが「/product/list」に変わる。
2. サーバー内部で「/product/list」に対応するビューに遷移し、URLは「/product/register」のまま変わらない。
3. ブラウザはPOSTリクエストで「/product/list」にアクセスする。
4. "redirect:" を付けた場合、ビュー名として「redirect:/product/list」というHTMLファイルを探す。

ステップ６：【model.addAttribute の役割と方向】に関する問題

問６. 以下のコードの説明として正しいものを選べ。

---Java---
@GetMapping("/item/list")
public String showList(Model model) {
    List<Item> items = itemService.findAll();
    model.addAttribute("itemList", items);
    return "item/list";
}
----------

1. model.addAttribute("itemList", items) は、コントローラからビューへデータを渡すためのメソッドである。
2. model.addAttribute("itemList", items) は、ビューからコントローラへデータを送るためのメソッドである。
3. model.addAttribute で追加した値は、セッションスコープに保存されるため次のリクエストでも参照できる。
4. model.addAttribute の第一引数には、クラス名を指定しなければならない。

正解：1番

ステップ７：【@Entity / @Id アノテーションの役割】に関する問題

問７. 以下のコードの説明として誤っているものを選べ。

---Java---
@Entity
@Table(name = "categories")
public class Category {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;

    private String categoryName;

    // getter/setter 省略
}
----------

1. @Entity を付与することで、このクラスがJPAのエンティティ（DBのテーブルと対応するクラス）として認識される。
2. @Table(name = "categories") は、対応するDBのテーブル名を指定している。
3. @Id を付与したフィールドが、テーブルの主キー列と対応する。
4. @Entity を付与したクラスは、コントローラから直接 @Autowired で注入して使用する。

正解：4番

ステップ８：【JpaRepository の findAll() の戻り値型】に関する問題

問８. 以下のコードの説明として正しいものを選べ。

---Java---
@Service
public class CategoryService {

    @Autowired
    private CategoryRepository categoryRepository;

    public List<Category> getAllCategories() {
        return categoryRepository.findAll();
    }
}
----------

1. findAll() の戻り値型は List 型であり、テーブルの全レコードをリストで返す。
2. findAll() の戻り値型は Optional 型であり、レコードが存在しない場合は空のOptionalを返す。
3. findAll() の戻り値型は Category 型であり、最初の1件のみを返す。
4. findAll() はリポジトリに別途定義しなければ使用できないメソッドである。

正解：1番

ステップ９：【th:text と th:value の違い】に関する問題

問９. 以下のコードの説明として正しいものを選べ。
ただし、コントローラから "productName" という名前で "りんご" が渡されているとする。

---Thymeleaf---
<p th:text="${productName}">商品名</p>
<input type="text" th:value="${productName}" name="productName">
----------

1. th:text は要素のテキスト内容を動的に書き換え、th:value は input要素のvalue属性を動的に書き換える。
2. th:text と th:value はどちらも input要素専用の属性であり、使い方は同じである。
3. th:text は input要素のvalue属性を書き換え、th:value は要素のテキスト内容を書き換える。
4. th:value を使用すると、フォーム送信時にその値はサーバーに送られない。

正解：1番

ステップ１０：【th:if / th:unless による条件分岐】に関する問題

問１０. 以下のコードの説明として正しいものを選べ。
ただし、コントローラから "isLoggedIn" という名前で「true」が渡されているとする。

---Thymeleaf---
<div th:if="${isLoggedIn}">
  <p>ログイン中です。</p>
</div>
<div th:unless="${isLoggedIn}">
  <p>ログインしていません。</p>
</div>
----------

1. isLoggedIn が true の場合、「ログイン中です。」のみが表示される。
2. isLoggedIn が true の場合、「ログイン中です。」と「ログインしていません。」の両方が表示される。
3. th:unless="${isLoggedIn}" は isLoggedIn が true のときに表示される。
4. th:if と th:unless を同一要素に同時に付与することで、排他的な表示切り替えができる。

正解：1番

ステップ１１：【#{} と ${} の使い分け（メッセージ式・変数式）】に関する問題

問１１. 以下のコードの説明として正しいものを選べ。

---Thymeleaf---
<h1 th:text="#{page.title}">タイトル</h1>
<p th:text="${userName}">ユーザー名</p>
----------

1. #{page.title} は messages.properties のキー「page.title」に対応する値を表示し、${userName} はコントローラから渡された変数を表示する。
2. #{page.title} はコントローラから渡された変数を表示し、${userName} は messages.properties の値を表示する。
3. #{} と ${} はどちらもコントローラから渡された変数を表示するための式であり、使い方は同じである。
4. ${userName} はThymeleaf独自の式であり、コントローラの Model に追加しなくても自動的に取得できる。

正解：1番

ステップ１２：【@Autowired の役割と付与対象】に関する問題

問１２. 以下のコードの説明として正しいものを選べ。

---Java---
@Controller
public class OrderController {

    @Autowired
    private OrderService orderService;

    @GetMapping("/order/list")
    public String showList(Model model) {
        model.addAttribute("orders", orderService.findAll());
        return "order/list";
    }
}
----------

1. @Autowired を付与することで、DIコンテナが OrderService のインスタンスを自動的に注入する。
2. @Autowired を付与したフィールドは、new キーワードで明示的にインスタンス生成する必要がある。
3. @Autowired はインターフェースには使用できず、具体的なクラスにのみ付与できる。
4. @Autowired はクラスに1つしか付与できない。

正解：1番
