public class BodyTempForm {

問4. 以下のフォームクラスのフィールド定義の説明として正しいものを選べ。

---Java---
public class PersonalInfoForm {

    @NotBlank
    private String name;

    @Pattern(regexp = "^[0-9]{3}-[0-9]{4}$")
    private String zipCode;

    @Size(min = 1, max = 100)
    private String address;

3. @Pattern は数値型（int, double）に対して使用でき、数値の範囲を正規表現で制限する。
4. @Size は数値の最大値・最小値を制限するアノテーションであり、文字列には使用できない。

ステップ5：【フィルタ - HttpFilter の実装】に関する問題
-----------------------------------------------------------------

問11. 以下のフィルタクラスのコードの説明として正しいものを選べ。

---Java---
@Component
public class URLCheckFilter extends HttpFilter {

    @Override
    protected void doFilter(HttpServletRequest request,
                            HttpServletResponse response,
                            FilterChain chain)
                            throws IOException, ServletException {

        String url = request.getRequestURI();

        if (url.endsWith("abc")) {
            response.sendRedirect("/practice/filter/xyz");
            return;
        }
        chain.doFilter(request, response);
    }
}
----------

1. リクエストのURLの末尾が "abc" の場合、コントローラに処理を引き渡さずに "/practice/filter/xyz" へリダイレクトさせる。
2. リクエストのURLの末尾が "abc" の場合、コントローラに処理を引き渡した後で "/practice/filter/xyz" へリダイレクトさせる。
3. @Component を付与しているため、このクラスはフィルタではなくサービスクラスとして動作する。
4. chain.doFilter を呼ばなくても、リクエストは自動的に次のフィルタまたはコントローラに転送される。

正解：1番

問12. 以下のコードの説明として誤っているものを選べ。

---Java---
@Configuration
public class FilterConfig {

    @Bean
    public FilterRegistrationBean<URLCheckFilter> filterA() {
        FilterRegistrationBean<URLCheckFilter> bean =
            new FilterRegistrationBean<>();
        bean.setFilter(new URLCheckFilter());
        bean.setOrder(1);
        return bean;
    }

    @Bean
    public FilterRegistrationBean<LogFilter> filterB() {
        FilterRegistrationBean<LogFilter> bean =
            new FilterRegistrationBean<>();
        bean.setFilter(new LogFilter());
        bean.setOrder(2);
        return bean;
    }
}
----------

1. URLCheckFilter は setOrder(1) が指定されているため、LogFilter より先に実行される。
2. FilterRegistrationBean を用いることで、複数フィルタの実行順序を明示的に制御できる。
3. @Configuration クラス内でフィルタを定義する場合、@Component をフィルタクラスに付けると二重登録になる可能性がある。
4. setOrder の値は文字列で指定する必要があり、数値を直接渡すとコンパイルエラーになる。

問20. 以下のコードの説明として誤っているものを選べ。

---Java---
@Controller
public class FortuneController {

    @GetMapping("/fortune")
    public String showFortune(Model model) {
        int score = (int)(Math.random() * 3) + 1;
        model.addAttribute("fortune", score);
        return "fortune";
    }
}
----------

---Thymeleaf（fortune.html）---
<div th:switch="${fortune}">
    <p th:case="1">大吉</p>
    <p th:case="2">中吉</p>
    <p th:case="3">凶</p>
</div>
----------

4. score の値は 0・1・2 のいずれかになるため、th:case="1"〜"3" はすべて一致せず、何も表示されないケースが存在する。
