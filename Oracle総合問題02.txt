問題1：CREATE USER文

ユーザ名が testuser、パスワードが system のユーザを作成したい。実行する SQL 文として正しいものはどれか。

- A. CREATE USER system MAKEDNAME BY testuser;
- B. CREATE USER testuser IDENTIFIED BY system;
- C. CREATE USER testuser SET PASSWORD system;
- D. CREATE PASSWORD system USERNAME testuser;

解答：B

解説：  
Oracleでユーザを作成しパスワードを設定する正しい構文は CREATE USER ユーザ名 IDENTIFIED BY パスワード; です。  
- Bが正解です。  
- A・C・D は実在しない構文または他のDBMSの構文です。

問題2：GRANT文

ユーザ scott に、「CREATE TABLE」という権限を割り当てたい。実行する SQL 文として正しいものはどれか。なお、「CREATE TABLE」は表を作成できる権限です。

- A. CREATE ROLE CREATE TABLE IDENTIFIED BY scott;
- B. GRANT CREATE TABLE TO scott;
- C. SET ROLE CREATE TABLE TO scott;
- D. REVOKE CREATE TABLE FROM scott;

解答：B

解説：  
権限をユーザに付与する正しい構文は GRANT 権限 TO ユーザ; です。  
- Bが正解です。  
- A・C は構文が誤っています。  
- D の REVOKE は権限を剥奪する際の構文です。

問題3：DROP USER文（CASCADE）

ユーザ taro のスキーマにはテーブルやビュー等のオブジェクトが保存されているとする。
これらも含めてまとめてユーザ taro を削除する場合に正しい SQL はどれか。

- A. DROP TABLE taro;
- B. DROP USER taro CASCADE;
- C. DROP USER taro;
- D. DROP TABLE taro CASCADE;

解答：B

解説：  
オブジェクトを所有しているユーザを削除するには DROP USER ユーザ名 CASCADE; を使用して、所有しているオブジェクトもまとめて削除する必要があります。  
- Bが正解です。  
- C の CASCADE なしの DROP USER では、オブジェクトが存在するためエラーになります。  
- A・D の DROP TABLE はテーブルを削除する構文です。

問題4：NOT NULL制約

下記のSQLを実行してstudentsテーブルを作成したい。gender列にある下線部に、必ず値を入れるための制約を記述する場合、正しい制約はどれか。

CREATE TABLE students (
id NUMBER(5) PRIMARY KEY ,
name VARCHAR2(10) ,
age NUMBER(2),
gender NUMBER(1) ________ ,
birthday DATE
);

- A. PRIMARY KEY
- B. NOT NULL
- C. UNIQUE
- D. FOREIGN KEY

解答：B

解説：  
「必ず値を入れる（NULLを許可しない）」ための制約は NOT NULL 制約です。  
- Bが正解です。  
- A の PRIMARY KEY は主キー制約（一意かつNOT NULL）ですが、ここではgender列に対する単一の必須入力要件を満たす NOT NULL が適切です。  
- C の UNIQUE は一意制約です。  
- D の FOREIGN KEY は外部キー制約です。

問題6：外部キー制約（表制約）

empテーブルのdeptno列からdeptテーブルの一意キーid列に外部参照できるように設定したい。実行するSQLとして正しいものはどれか。

- A.

- B. 
CREATE TABLE emp (
(中略)

問題10：INSERT文（列と値の数が不一致）

itemsテーブルに対して、下記のSQL文でレコードの登録を行いたい。想定される結果として正しいものはどれか。

INSERT INTO items(id, name, category) VALUES(1, 'book', 3, 3);

なお、itemsのテーブル定義は下記内容であり、itemsテーブルにはまだ1レコードも登録されていないとする。

列名        型            制約
---------   ------------- ------------
id          NUMBER(5)     PRIMARY KEY
name        VARCHAR2(10)
category    NUMBER(2)
stock       NUMBER(5)


- A. レコードが登録され、stock列には3が登録される。
- B. レコードが登録され、stock列には0が登録される。
- C. レコードが登録され、stock列にはnullが登録される。
- D. 実行時にエラーが発生する。

解答：D

解説：  
INSERT文で指定した列数（id, name, category の3つ）に対して、VALUES句で指定した値の数（1, 'book', 3, 3 の4つ）が一致していません。  
- 列数と値の数が異なるため、Dの「実行時にエラーが発生する」が正解です。

問題11：UPDATE文（複数列の更新）

empテーブル中でempno列が8000のレコードに対して、下記内容に更新したい。実行するSQL 文として正しいものはどれか。

更新対象の列名 更新後の値
------------- -----------
deptno        10
sal           3000


- A. UPDATE emp SET deptno = 10 AND sal = 3000 WHERE empno = 8000;
- B. UPDATE emp SET VALUES(deptno = 10, sal = 3000) WHERE empno = 8000;
- C. UPDATE emp SET deptno = 10, sal = 3000 WHERE empno = 8000;
- D. UPDATE emp SET deptno = 10, sal = 3000, empno= 8000;

解答：C

解説：  
UPDATE文で複数の列を更新する場合は、SET 列1 = 値1, 列2 = 値2 のようにカンマで区切ります。  
- Cが正しい構文です。  
- A の AND はWHERE句の条件結合用でありSET句では使えません。  
- B の VALUES はINSERT文の構文です。  
- D は WHERE 句の指定がなく、empno の更新が含まれてしまっています。

問題13：トランザクションとCOMMIT

あなたはOracle Databaseを使用したデータベースの運用業務を行っている。あなたは業務指示により、レコード数0行のitemsテーブルに対して下記のSQL文2行を正常に実行した後、作業完了と判断して別の業務に移った。

INSERT INTO items VALUES(1, 'apple', 1, 20);
INSERT INTO items VALUES(2, 'orange', 1, 30);

その後、他のメンバーから作業が完了していないとの指摘を受けた。
Oracle Databaseの仕様上の観点で、最も正しい理由はどれか。
なお、対象のデータベースのトランザクションに関する設定はデフォルト状態だとする。

- A. 実行後にデータベースとの接続を切っていなかったから。
- B. 実行後にデータベースを再起動していなかったから。
- C. 実行後にSELECT文を実行していなかったから。
- D. 実行後にCOMMIT文を実行していなかったから。

解答：D

解説：  
INSERT等のDML文を実行しただけでは、変更は確定されておらず他のユーザからは見えません。  
- 変更をデータベースに確定させ、他のユーザからも参照できるようにするには COMMIT 文を実行する必要があります。したがってDが正解です。

-- ---------- --- ------ --------

上記のstudentsテーブルに対して、1人目のデータベース利用者が下記のSQL文を実行した。

同じタイミングで2人目のデータベース利用者が下記のSQL文を実行した。このとき、2人目のデータベース利用者側での実行結果として正しいものはどれか。

SQL> SELECT * FROM students;

- B.

問題15：SAVEPOINTを含むSQL文の動作

SQL> SELECT empno, ename FROM emp;

EMPNO ENAME
----- ------
8000  DAVID

上記のempテーブルに対して以下のSQL文を実行した。

SQL> INSERT INTO emp(empno, ename) VALUES(9000, 'RYAN');
SQL> SAVEPOINT A;
SQL> INSERT INTO emp(empno, ename) VALUES(9001, 'ROY');
SQL> SAVEPOINT B;
SQL> INSERT INTO emp(empno, ename) VALUES(9002, 'ALEX');
SQL> ROLLBACK TO A;

その後、 empテーブルに対して以下のSQL文を実行した。このときの実行結果として正しいものはどれか。

SQL> COMMIT;
SQL> SELECT empno, ename FROM emp;

- A. 
EMPNO ENAME
----- ------
9000  RYAN

- B. 
EMPNO ENAME
----- ------
8000  DAVID
9000  RYAN
9001  ROY

- C. 
EMPNO ENAME
----- ------
8000  DAVID
9000  RYAN
9001  ROY
9002  ALEX

- D. 
EMPNO ENAME
----- ------
8000  DAVID
9000  RYAN

解答：D

解説：  
ROLLBACK TO A; によって、SAVEPOINT A 以降に実行された処理（ROYとALEXのINSERT）が取り消されます。  
- その後 COMMIT; されるため、元のDAVIDと、SAVEPOINT A の前に実行されたRYANのINSERTのみが確定します。よってDが正解です。

問題20：集約関数SUM・GROUP BY句

SQL> SELECT * FROM items;

ID NAME       CATEGORY STOCK
-- ---------- -------- -----
1  apple      1        20
2  orange     1        30
3  banana     1        40

上記のitemsテーブルに対して下記SQL文を実行した。想定される結果として正しいものはどれか。

SQL> SELECT category, SUM(stock) FROM items GROUP BY category;

- A. 
CATEGORY SUM(stock)
-------- ----------
1        20
2        30
3        40

- B. 
CATEGORY SUM(stock)
-------- ----------
1        90

- C. 
CATEGORY SUM(stock)
-------- ----------
1        20,30,40

- D. 実行時にエラーが発生する。

解答：B

解説：  
GROUP BY category によりカテゴリ単位でグループ化され、同じ category = 1 の stock（20, 30, 40）が SUM 関数によって合算されます。  
- 20 + 30 + 40 = 90 となり、結果は 1 | 90 となるため、Bが正解です。

問題21：集約関数・GROUP BY・HAVING句

JOB       MAX(SAL)

PRESIDENT 5000

ANALYST   3000

- B. SELECT job, MAX(sal) FROM emp GROUP BY job WHERE MAX(sal) > 2000;

問題22：結合（テーブル指定の記述ミス）

SQL> SELECT * FROM students;

ID NAME       CLASS_ID
-- ---------- --------
1  Tanaka     1
2  Suzuki     1
3  Sato       2

SQL> SELECT * FROM class_rooms;

CLASS_ID CLASS_NAME
-------- ----------
1        classA
2        classB
3        classC

上記のstudentsテーブルとclass_roomsテーブルを内部結合する下記のSQL文を実行したところエラーが発生した。原因として正しいものはどれか。

SQL> SELECT id, name, class_id, class_name
     FROM students
     INNER JOIN class_rooms ON students.class_id = class_rooms.class_id;

なお、studentsテーブルのclass_id列はclass_roomsテーブルのclass_id列を外部参照しているとする。

- A. FROM句で各テーブルに別名を付けていない。
- B. SELECT句でclass_id列がどのテーブルの列であるか明記されていない。
- C. ON句で同名の列名での比較を行っている。

解説：  
結合する複数のテーブルに同じ名前の列（class_id）が存在する場合、SELECT句などで単に class_id と指定すると、どちらのテーブルの列か判別できず「列の定義があいまいです」というエラーが発生します。  
- テーブル名または別名で students.class_id のように修飾する必要があるため、Bが正解です。

問題23：左外部結合の実行結果（レコード数）

SQL> SELECT * FROM employee;

EMP_ID EMP_NAME   DEPT_ID
------ ---------- -------
1      田中太郎   2
2      鈴木二郎   2
3      渡辺花子   3
4      佐藤達夫   3

SQL> SELECT * FROM dept;

DEPT_ID DEPT_NAME
------- ----------
1       総務部
2       営業部
3       開発部

上記のemployeeテーブルとdeptテーブルをLEFT OUTER JOIN（左外部結合）で結合し、結合結果の「レコード数」を出力したい。「deptテーブル」を基準のテーブルとする場合、以下のSQL文となる。このSQL文を実行したときに出力されるレコード数の値として正しいものはどれか。

SQL> SELECT COUNT(*)
     FROM dept LEFT OUTER JOIN employee
     ON dept.dept_id = employee.dept_id;

- A. 2
- B. 3
- C. 4
- D. 5

解答：D

解説：  
LEFT OUTER JOIN は、基準となる左側のテーブル（dept）の全レコードを必ず出力し、条件に一致する右側のテーブル（employee）のレコードを結合します。  
- dept_id = 1 の行（一致0件で1行）、dept_id = 2 の行（一致2件で2行）、dept_id = 3 の行（一致2件で2行）となり、合計5行が出力されるためDが正解です。

問題24：左外部結合の正しいSQL文

SQL> SELECT * FROM products;

PRODUCT_ID PRODUCT_NAME CATEGORY_ID
---------- ------------ -----------
1          Apple        1
2          Orange       1
3          Banana       2

SQL> SELECT * FROM categories;

CATEGORY_ID CATEGORY_NAME
----------- -------------
1           Fruit
2           Fruit
3           Vegetable

上記の products テーブルと categories テーブルを結合し、「すべてのカテゴリID（category_id）とカテゴリ名（category_name）」を出力するSQL文として正しいものはどれか。

- A. SELECT c.category_id, c.category_name, p.product_name FROM categories c LEFT OUTER JOIN products p ON c.category_id = p.category_id;
- B. SELECT c.category_id, c.category_name, p.product_name FROM categories c INNER JOIN products p ON c.category_id = p.category_id;
- C. SELECT c.category_id, c.category_name, p.product_name FROM categories c RIGHT OUTER JOIN products p ON c.category_id = p.category_id;
- D. SELECT c.category_id, c.category_name, p.product_name FROM products p LEFT OUTER JOIN categories c ON c.category_id = p.category_id;

解答：A

解説：  
「すべてのカテゴリ」を出力するには、categories テーブルを基準とした外部結合を行う必要があります。  
- categories テーブルを左側に配置して LEFT OUTER JOIN を使用している A が正解です。  
- D は categories が右側ですが LEFT OUTER JOIN なので products が基準になってしまいます。

問題25：サブクエリ（実行結果を得るための記述）

列名        型            制約
---------   ------------- ------------
id          NUMBER(5)     PRIMARY KEY
name        VARCHAR2(10)
category    NUMBER(2)
stock       NUMBER(5)

上記のテーブル定義を持つitemsテーブルに対して、「stock列の値が10未満という条件で絞り込み検索するサブクエリの結果から、name列の値のみを出力する」処理を実行したい。上記の要件を満たすSQL文として正しいものはどれか。

- A. SELECT name FROM SELECT * FROM items WHERE stock < 10;
- B. SELECT name FROM (SELECT stock FROM items WHERE stock < 10);
- C. SELECT name FROM (SELECT * FROM items WHERE stock < 10);
- D. SELECT name FROM (SELECT * FROM items) WHERE stock < 10;

解答：C

解説：  
FROM句にサブクエリ（インラインビュー）を記述する場合、サブクエリ全体を括弧 () で囲む必要があります。  
- サブクエリから name 列を取得するには、サブクエリのSELECT句で name 列（または * ）が取得されている必要があります。B は stock しか取得していないためエラーになります。  
- 条件付きで全列を取得するサブクエリを正しく括弧で囲んでいる C が正解です。

問題26：WHERE句でのスカラ・サブクエリ

(問題7と同じempテーブルに対し)
上記のempテーブルを使用して、sal列の値が全レコードの平均値以上であるレコードのみを検索したい。実行するSQL文として正しいものはどれか。

- A. SELECT * FROM emp WHERE sal >= (SELECT AVG(sal) FROM emp);
- B. SELECT * FROM emp WHERE sal >= AVG(sal);
- C. SELECT * FROM (SELECT AVG(sal) FROM emp);
- D. SELECT * FROM (SELECT AVG(sal) FROM emp GROUP BY sal HAVING sal >= AVG(sal));

解答：A

解説：  
WHERE句で集約関数（AVGなど）の計算結果と比較するには、サブクエリを使用する必要があります。  
- WHERE sal >= (平均値を求めるサブクエリ) と記述している A が正解です。  
- WHERE句に直接 AVG(sal) と記述する B はエラーになります。

問題27：スカラ・サブクエリにならない記述

(問題7と同じempテーブルに対し)
上記のempテーブルに対して下記のSQL文を実行したところエラーが発生した。原因として正しいものはどれか。

SELECT empno, ename, sal FROM emp
WHERE deptno = (
  SELECT deptno FROM emp WHERE sal = (
    SELECT MIN(sal) FROM emp GROUP BY job
  )
);

- A. サブクエリが入れ子になって記述されている。
- B. サブクエリが1 行 1 列の検索結果を返さない。
- C. 一番外側のSELECT句にdeptno列の指定がない。
- D. 一番内側のSELECT句で集約関数を使用している。

解答：B

解説：  
WHERE sal = (サブクエリ) のように = などの単一行比較演算子を使用する場合、サブクエリは必ず 1行1列 の結果（スカラ値）を返す必要があります。  
- 一番内側のサブクエリで GROUP BY job によって職種ごとに複数の結果が返されるためエラーになります。したがって B が正解です。
