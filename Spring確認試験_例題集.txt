ステップ１：【@RequestMapping アノテーション】に関する問題

問１. 以下のコードの説明として正しいものを選べ。

---Java---
@Controller
public class SampleController {

    @RequestMapping(value = "/hello", method = RequestMethod.GET)
    public String hello() {
        return "hello";
    }
}
----------

1. GETリクエストで「/hello」にアクセスしたとき、このメソッドが実行される。
2. POSTリクエストで「/hello」にアクセスしたとき、このメソッドが実行される。
3. GETリクエストとPOSTリクエストの両方で「/hello」にアクセスしたとき、このメソッドが実行される。
4. method属性を省略しているため、このメソッドは実行されない。

ステップ７：【セッションスコープを利用するメソッド定義】に関する問題

問７. 以下のコードの説明として正しいものを選べ。

---Java---
@Controller
@SessionScope
public class CartController {

    @Autowired
    private CartForm cartForm;

    @GetMapping("/cart")
    public String showCart(Model model) {
        model.addAttribute("cartForm", cartForm);
        return "cart/index";
    }

----------

3. @SessionScope はメソッドにのみ付与可能であり、クラスに付与しても効果はない。
4. @SessionScope を付与すると、ブラウザを閉じるたびに自動的にセッションが削除される。

正解：1番

ステップ１０：【主キー列にシーケンスを利用するエンティティ定義】に関する問題

問１０. 以下のコードの説明として誤っているものを選べ。

---Java---
@Entity
@Table(name = "products")
public class Product {

    @Id
    @GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "product_seq")
    @SequenceGenerator(name = "product_seq", sequenceName = "product_id_seq", allocationSize = 1)
    private Integer id;

    private String productName;

    // getter/setter 省略
}
----------

1. @Id はこのフィールドが主キーであることを示している。
2. @GeneratedValue の strategy = GenerationType.SEQUENCE は、シーケンスを使って主キーを自動生成することを示す。
3. @SequenceGenerator の sequenceName 属性には、データベース上のシーケンス名を指定する。
4. @SequenceGenerator を使用すると、@Id の指定は不要になる。

正解：4番

ステップ１１：【DBへのエンティティ登録処理】に関する問題

問１１. 以下のコードのうち、DBへの登録処理として不具合の原因とならないものを選べ。

---Java---
@Service
public class ProductService {

    @Autowired
    private ProductRepository productRepository;

    public void registerProduct(ProductForm form) {

        // (A) エンティティオブジェクトを生成する
        Product product = new Product();

        // (B) フォームの値をエンティティにセットする
        product.setProductName(form.getProductName());
        product.setPrice(form.getPrice());

        // (C) IDに固定値をセットしてからsaveを呼ぶ
        product.setId(1);
        productRepository.save(product);
    }
}
----------

1. (A) エンティティのオブジェクトを new で生成している。
2. (C) IDに固定値「1」を明示的にセットしているため、IDが「1」のレコードが既存の場合は上書きされる。
3. (C) IDに固定値をセットすると、シーケンスによる自動採番が機能しない。
4. (C) IDに固定値をセットすると、新規登録か更新かの判定がIDの有無で行われるため、意図しない更新が発生する可能性がある。

正解：1番

---Java---
@Entity

    @ManyToOne
    @JoinColumn(name = "customer_id")

3. @JoinColumn(name = "customer_id") は、Customerエンティティのクラス名を指定している。

---Java---
@Query("SELECT new com.example.dto.ProductDto(p.id, p.productName) FROM Product p")

----------

ステップ１６：【フォームクラスへのバリデーションアノテーション（@NotNull と数値型）】に関する問題

問１６. 以下のコードの説明として正しいものを選べ。

---Java---
public class ItemForm {

    @NotBlank
    private String itemName;

    @NotNull
    private Integer price;

    // getter/setter 省略
}
----------

1. @NotNull を Integer 型のフィールドに付与すると、フォームから値が送信されなかった場合（null）にエラーが発生する。
2. @NotNull を Integer 型のフィールドに付与すると、空文字（""）の送信もバリデーションエラーになる。
3. Integer 型に @NotBlank を付与することで、数値の形式チェックが行える。
4. @NotNull は String 型専用のアノテーションであり、Integer 型には使用できない。

正解：1番

---Thymeleaf---

  <td th:text="${stat.count}">1</td>

ステップ２１：【レイアウトテンプレートへの個別画面の埋め込み】に関する問題

問２１. 以下のコードの説明として正しいものを選べ。

---Thymeleaf（レイアウトテンプレート layout.html）---
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org"
      xmlns:layout="http://www.ultraq.net.nz/thymeleaf/layout"
      layout:decorate="~{layout/layout}">
<head>
  <title>サンプル</title>
</head>
<body>
  <div layout:fragment="content">
    <p>ここに個別ページのコンテンツが埋め込まれます。</p>
  </div>
</body>
</html>
----------

---Thymeleaf（個別画面 detail.html）---
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org"
      xmlns:layout="http://www.ultraq.net.nz/thymeleaf/layout"
      layout:decorate="~{layout/layout}">
<body>
  <div layout:fragment="content">
    <p th:text="${product.name}">商品名</p>
  </div>
</body>
</html>
----------

1. 個別画面で layout:fragment="content" を宣言したブロックが、レイアウトテンプレートの同名 fragment の箇所に埋め込まれる。
2. layout:decorate はレイアウトテンプレート側のみに記述し、個別画面側には記述しない。
3. layout:fragment を使用するには、th:replace によって個別画面全体を置き換える必要がある。
4. th:fragment と layout:fragment は同一のアノテーションであり、どちらを使っても動作は変わらない。

正解：1番
