【変数】に関する問題

問1. String型の変数に代入できるものとして正しいものを選べ。

1. true または false のみ代入できる。
2. 整数値のみ代入できる。
3. 文字列（テキスト）を代入できる。
4. 小数点を含む数値のみ代入できる。

正解：3番

【解説】
String型はJavaで文字列を扱うためのクラス型です。
  例）String name = "Java研修";
・1番：true/falseはboolean型の値です。
・2番：整数値はint型などの数値型に代入します。
・4番：小数点を含む数値はdouble型やfloat型に代入します。
Stringは文字列専用の型と覚えておきましょう。

問2. 以下のコードの実行結果として正しいものを選べ。

---Java---
int num = 5;
num = num + 3;
System.out.println(num);
----------

1. 5
2. 3
3. 8
4. 53

正解：3番

【解説】
  int num = 5;    // numに5を代入
  num = num + 3;  // 5 + 3 = 8 をnumに再代入
  System.out.println(num); // 8を出力

・1番：初期値の5のままでは、num = num + 3 の処理がないことになります。
・2番：3は加算する値であり、結果ではありません。
・4番：53は文字列連結の誤解です（数値の足し算なので8が正解）。

【演算子】に関する問題

問3. 以下の式の出力結果として正しいものを選べ。

System.out.println("点数：" + 90 + 10);

1. 点数：100
2. 点数：9010
3. 点数：90
4. エラーになる

正解：2番

【解説】
Javaの+演算子は左から右に評価されます。
  "点数：" + 90  → 文字列連結 → "点数：90"
  "点数：90" + 10 → 文字列連結 → "点数：9010"

文字列の後ろに数値を+すると、数値は文字列として連結されます。
・1番：100になるのは (90 + 10) が先に計算される場合ですが、
       文字列の後では算術計算にはなりません。
・3番：10が連結されていないため誤りです。

問4. 型変換に関する説明として正しいものを選べ。

1. int型の値をdouble型の変数に代入するにはキャスト演算子が必要である。
2. double型の値をint型の変数に代入すると、自動的に変換される。
3. int型はdouble型より小さい型のため、代入するだけで自動的にdouble型に変換される。
4. booleanはint型に自動変換できる。

正解：3番

【解説】
型の大きさ：byte < short < int < long < float < double
小さい型 → 大きい型への代入：キャスト不要（自動変換）
大きい型 → 小さい型への代入：キャスト必須

  int i = 10;
  double d = i;  // 自動変換OK（10.0になる）

・1番：逆の説明です。int→doubleはキャスト不要です。
・2番：double→intが「自動変換される」は誤りです（キャスト必須）。
・4番：booleanはint型に変換できません（Javaの仕様）。

ただし、配列fruitsには{"りんご", "みかん", "ぶどう"}が代入されているとする。

System.out.println(fruits[?]);

1. fruits[0]
2. fruits[1]

配列の添字（インデックス）は0から始まります。
  fruits[0] = "りんご"
  fruits[1] = "みかん"  ← 正解
  fruits[2] = "ぶどう"

・1番：fruits[0]は「りんご」です。
・3番：fruits[2]は「ぶどう」です。
・4番：fruits[3]は存在せず、実行するとArrayIndexOutOfBoundsExceptionが発生します。

問6. 以下の文はどのような処理を行うか。正しいものを選べ。

String[] names = new String[3];

1. String型の値を3個まで保存できる配列を生成し、変数namesに代入する。
2. String型の値を4個まで保存できる配列を生成し、変数namesに代入する。
3. 変数namesにString型の文字列「3」を代入する。

  String[] names = new String[3];

【分岐】に関する問題

問7. 以下のif文で「合格」と表示されるために変数scoreに代入すべき値として正しいものを選べ。

---Java---
if (score >= 70) {
    System.out.println("合格");
} else {
    System.out.println("不合格");
}
----------

1. 65
2. 69
3. 70
4. 50

正解：3番

問7. 正解：3番「70」

【解説】
  if (score >= 70) → scoreが70以上なら「合格」と表示
  70以上：60❌ 69❌ 70✅

・1番：65は70未満なので「不合格」になります。
・2番：69は70未満なので「不合格」になります。
・4番：50は70未満なので「不合格」になります。
条件式が「>= 70」（70以上）なので、ちょうど70も合格です。

問8. switch文でbreak文を省略した場合の動作として正しいものを選べ。

1. そのcase文だけが実行され、次のcase文には進まない。
2. 一致したcaseから始まり、次のbreakまたはswitch文の末尾まで処理が続く。
3. コンパイルエラーが発生する。
4. 全てのcase文が最初から順番に実行される。

正解：2番

【解説】
switch文でbreak文を省略すると「フォールスルー（fall-through）」が発生します。
一致したcaseから処理が開始し、次のbreakが出るまで下のcaseの処理も連続して実行されます。

・1番：break文がある場合の動作です。
・3番：break省略はコンパイルエラーにはなりません。
・4番：全caseが実行されるのではなく、「一致したcase以降」が実行されます。

【繰り返し】に関する問題

問9. 以下のfor文が繰り返す回数として正しいものを選べ。

---Java---
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
----------

1. 4回
2. 5回
3. 6回
4. 1回

正解：2番

【解説】
  for (int i = 0; i < 5; i++)
  i=0, 1, 2, 3, 4 → 条件 i<5 を満たす間繰り返す
  → 合計5回実行（0, 1, 2, 3, 4 を出力）

・1番：4回はi=0〜3の4回と誤解した場合です。
・3番：i<5なのでi=5では実行されません（6回は誤り）。
・4番：iは毎回1増えるため無限ループにはなりません。

問10. 以下のwhile文の実行結果として正しいものを選べ。

---Java---
int i = 1;
while (i <= 3) {
    System.out.println(i);
    i++;
}
----------

1. 1, 2 が順に表示される
2. 1, 2, 3 が順に表示される
3. 1, 2, 3, 4 が順に表示される
4. 無限ループになる

正解：2番

【解説】
  int i = 1;
  while (i <= 3) → iが3以下の間繰り返す
  i=1: 1を出力 → i=2
  i=2: 2を出力 → i=3
  i=3: 3を出力 → i=4
  i=4: 条件4<=3 が偽 → ループ終了

・1番（誤り選択肢）：1, 2のみは i<=2 の条件の場合です。
・3番：4が表示されるのはi<=4の条件の場合です。
・4番：i++でiが増えているため無限ループにはなりません。

【メソッド】に関する問題

問12. メソッドの戻り値の説明として正しいものを選べ。

1. 戻り値はメソッド内で発生したエラーを呼び出し元に通知するために使用する。
2. 戻り値はメソッドを呼び出した側に処理結果を返すために使用する。
3. 戻り値はメソッドに値を渡すために使用する。
4. 戻り値の型は必ずvoidと記述しなければならない。

正解：2番

【解説】
メソッドの戻り値（return値）は、メソッドの処理結果を呼び出し元に渡す仕組みです。
  int result = add(3, 5);  // add()の戻り値8がresultに入る

・1番：エラー情報を渡すのは例外（Exception）の役割です。
・3番：引数は「渡す」ためのもの。戻り値はそれとは逆方向（返す）です。
・4番：voidは戻り値が「なし」を意味します。voidでないメソッドも存在します。

【アクセス修飾子】に関する問題

問13. private修飾子が付いたフィールドの説明として正しいものを選べ。

1. 全てのクラスからアクセスできる。
2. 同じパッケージ内のクラスからのみアクセスできる。
3. そのフィールドが定義されたクラス内からのみアクセスできる。
4. サブクラスからのみアクセスできる。

正解：3番

アクセス修飾子のまとめ：
  private   → 同じクラス内のみ
  (なし)    → 同じパッケージ内
  protected → 同パッケージ＋サブクラス
  public    → すべてのクラス

・1番：publicの説明です。
・2番：パッケージプライベート（修飾子なし）の説明です。
・4番：protectedの一部の説明です（サブクラスも含む）。

【オーバーロード】に関する問題

問15. オーバーロードできないメソッドの組み合わせはどれか。

1. void print(int n) と void print(double d)
2. void print(String s) と void print(int n)
3. void print(int n) と int print(int n)
4. void print(int n, String s) と void print(String s, int n)

正解：3番

【解説】
オーバーロードの条件：「引数の型または数が異なること」
戻り値の型だけが違うメソッドはオーバーロードできません。

  void print(int n) と int print(int n)
  → 引数が同じ(int n)で戻り値だけ違う → オーバーロード不可

・1番：引数の型が違う（int vs double）→ オーバーロード可
・2番：引数の型が違う（String vs int）→ オーバーロード可
・4番：引数の数が違う（1個 vs 2個）→ オーバーロード可

1. 同じクラス内に同じ名前・同じ引数のメソッドを複数定義できること。
2. 同じクラス内に同じ名前で引数の型や数が異なるメソッドを複数定義できること。
3. 異なるクラス間で同じ名前のメソッドを定義できること。

正解：2番

【解説】
オーバーロードとは：同じクラス内で、同名で引数が異なるメソッドを複数定義すること。

・1番：同じ引数のメソッドは定義できません（コンパイルエラー）。
・3番：異なるクラス間の定義はオーバーロードとは呼びません。
・4番：親クラスのメソッドを子クラスで再定義するのは「オーバーライド」です。

【コンストラクタ】に関する問題

問17. コンストラクタの定義として間違っているものを選べ。
ただし、クラス名はAnimalとする。

1. public Animal() { }
2. public void Animal() { }
3. public Animal(String name) { }
4. Animal() { }

正解：2番

【解説】
コンストラクタの定義ルール：
  1. クラス名と同じ名前にすること
  2. 戻り値の型を書かないこと（voidも不可）

  public void Animal() { }
  → voidが書かれているためコンストラクタではなく通常のメソッドとして扱われます。
  → 厳密にはコンパイルエラーにはなりませんが、コンストラクタとして機能しません。

・1番：戻り値なし、クラス名一致 → 正しいコンストラクタです。
・3番：引数あり → 正しいコンストラクタです。
・4番：アクセス修飾子なし → 有効なコンストラクタです。

・4番：コンストラクタにstatic修飾子は付けられません。

【staticメンバ】に関する問題

問19. static変数に関する説明として正しいものを選べ。

1. static変数はオブジェクトごとに個別の値を持つ。
2. static変数はクラス全体で1つの値を共有する。
3. static変数はprivate修飾子と組み合わせることができない。

正解：2番

static変数（クラス変数）はクラスに1つだけ存在し、全オブジェクトで共有されます。

  c1.count++; // count = 1
  c2.count++; // 同じcount → count = 2

・1番：インスタンス変数（非static）の説明です。
・3番：static変数はprivateとも組み合わせ可能です。
・4番：static変数はクラスフィールドとして定義します（メソッド内ではない）。

問26. パッケージ「jp.co.sss.util」にあるクラス「StringUtil」を使用するimport文として正しいものを選べ。

4. include jp.co.sss.util.StringUtil;

正解：3番

【解説】
特定のクラス1つをインポートする場合は完全クラス名を指定します。
  import パッケージ名.クラス名;
  import jp.co.sss.util.StringUtil;

・1番：クラス名が含まれていません（パッケージのみ）。
・2番：jp.co.sss.util.*はパッケージ内の全クラスをインポートします（1クラスではない）。
・4番：includeはJavaの文法ではありません（C/C++の記法）。

【例外】に関する問題

問27. チェック例外が発生する可能性があるコードを書く際に、コンパイルエラーが出ないようにする方法として正しいものを選べ。

1. 例外が発生するコードをif文で囲む。
2. try-catch文で例外をキャッチするか、throwsでメソッドに例外を宣言する。
3. 例外が発生する行にコメントを付ける。
4. 変数名を変更することで例外を回避できる。

正解：2番

【解説】
チェック例外（IOException等）は、必ずどちらかの対処が必要です。

  方法A：try-catch で囲む
    try { br.readLine(); } catch(IOException e) { ... }

  方法B：メソッドにthrowsを宣言する
    void readData() throws IOException { br.readLine(); }

・1番：if文は例外処理の仕組みではありません。
・3番：コメントは実行時の例外に影響しません。
・4番：変数名の変更は例外の発生とは無関係です。

問28. 以下の文はどのような処理を行うか。正しいものを選べ。

throw new IllegalArgumentException("無効な引数です");

1. IllegalArgumentExceptionクラスを新しく定義する。
2. IllegalArgumentExceptionをキャッチして処理する。
3. IllegalArgumentExceptionのオブジェクトを生成し、例外として発生させる。
4. 「無効な引数です」という文字列を出力する。

正解：3番

【解説】
throw文は例外を意図的に発生させる（スローする）ための文です。
  throw new IllegalArgumentException("無効な引数です");
  → new で例外オブジェクトを生成
  → throw で例外として発生させる

・1番：クラスを定義するのはclassキーワードです。
・2番：例外をキャッチするのはcatch文です。
・4番：メッセージを出力するだけの処理ではありません。

問30. HashMapの正しい宣言・生成方法を選べ。

1. HashMap map = new HashMap(String, Integer);
2. HashMap<String, Integer> map = new HashMap<>();
3. HashMap<String, Integer> map = HashMap();
4. new HashMap<String, Integer> map = new HashMap<>();

正解：2番

【解説】
HashMapの正しい宣言と生成：
  HashMap<キーの型, 値の型> 変数名 = new HashMap<>();

  HashMap<String, Integer> map = new HashMap<>();

・3番：new HashMap()が必要ですが、()が不要な記法になっています。
・4番：宣言と生成の順序が間違っています。
